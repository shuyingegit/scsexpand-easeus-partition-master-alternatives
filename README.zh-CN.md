## 决定选型的四个问题

1. **免费版能不能真的扩容？** 上列多数工具的「免费」覆盖的是扫描与缩小卷，而真正想要的「扩 C 盘并把空间挪过来」是付费操作。
2. **来源空间是否在同一块物理盘？** 另一块盘上的空闲空间无法「借」给 C 盘——resize 改写的是同一块盘的分区表；声称能跨盘的工具，做的其实是复制或迁移。
